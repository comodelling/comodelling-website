# Projects


Here you'll find our tools and platforms for co-modelling. <br>
All software we make is free and open source, and platforms we build aim to provide open data.<br>


## CommonGraph

[CommonGraph](https://github.com/comodelling/commongraph/) is a platform builder for graph-based collaboration.<br>
It enables groups to define their own ontology and lets users explore and contribute to the shared knwoledge graph collaboratively.<br>
For setup and configuration, check out its [documentation](https://commongraph.org/).


## CommonOutcomes

[CommonOutcomes](https://commonoutcomes.org) is a platform powered by CommonGraph with a view to collaboratively map and evaluate actions and outcomes.
It is currently in beta-testing phase, [let us know](mailto:contact@comodelling.org) if you would like to take part!
